🧮 Calculator Web App

A simple and stylish calculator built using HTML, CSS, and JavaScript.
This project demonstrates basic UI design, JavaScript event handling, and dynamic DOM updates.

🚀 Features

Fully functional calculator

Clean UI with dark theme

Supports addition, subtraction, multiplication, and division

Live output displayed on screen

Responsive circular buttons

Simple and beginner-friendly JavaScript

🛠️ Technologies Used

HTML – Calculator structure

CSS – Styling and layout

JavaScript – Logic for performing calculations

📜 How It Works

Buttons append values to a calculation string

Display updates through a modified console.log()

eval() evaluates the final expression

Clear resets the calculator

▶️ How to Run

Clone or download the repository

Open index.html in any browser

Start using the calculator!
